Day 2: Basic HTML Structure

Anatomy of an HTML Element

As we touched upon yesterday, an HTML element usually consists of a start tag, content, and an end tag. Let's delve deeper into this:

  • Start Tag: It marks the beginning of an element and is enclosed in angle brackets (e.g., <p>).
  • Content: This is the information that appears between the start and end tags (e.g., "This is a paragraph.").
  • End Tag: It marks the end of an element. End tags look like start tags but have a forward slash before the element name (e.g., </p>).

For example, in <h1>My Main Title</h1>, <h1> is the start tag, "My Main Title" is the content, and </h1> is the end tag.

Nesting HTML Elements

HTML elements can be nested within each other. This means you can have one element inside another. Proper nesting is crucial for the browser to correctly interpret your HTML structure. 


<div>
    <p>This paragraph is inside a <strong>div</strong> element.</p>
</div>

In this example, the <p> element and the <strong> element are nested within the <div> element. It's important to close the inner elements before closing the outer ones. Incorrect nesting can lead to unexpected behavior and make your HTML harder to read and maintain. 


<!-- Incorrect Nesting -->
<p><strong>This is bold text.</p></strong>

<!-- Correct Nesting -->
<p><strong>This is bold text.</strong></p>

Block-Level vs. Inline Elements

HTML elements can be categorized into two main types based on how they behave in terms of layout: block-level and inline elements.

Block-Level Elements

  • Block-level elements always start on a new line and take up the full width available (stretching out to the left and right as far as they can).
  • They can contain both inline and other block-level elements.
  • Examples of common block-level elements include: <div>, <p>, <h1> to <h6>, <ul>, <ol>, <li>, <form>, <header>, <footer>, <section>. 

<div style="border: 1px solid red;">This is a block-level div.</div>
<p style="border: 1px solid green;">This is a block-level paragraph.</p>

Inline Elements

  • Inline elements do not start on a new line and only take up as much width as necessary.
  • They typically contain only data or other inline elements.
  • Examples of common inline elements include: <span>, <a>, <strong>, <em>, <img>, <input>, <textarea>, <select>. 

<span style="border: 1px solid blue;">This is an inline span.</span>
<strong style="border: 1px solid orange;">This is inline bold text.</strong>

Understanding the difference between block-level and inline elements is crucial for controlling the layout and structure of your web pages.

Attributes

Attributes provide extra information about HTML elements. They are always specified in the start tag. Attributes usually come in name/value pairs like: name="value".

  • Common Attributes: Some common attributes include id (to uniquely identify an element), class (to classify elements), style (to add inline styles), src (for images), href (for links), and alt (for image descriptions).
  • Global Attributes: These are attributes that can be used on almost any HTML element (e.g., id, class, style, title, lang). 

<p id="intro" class="main-paragraph" style="color: green;">This paragraph has an ID, a class, and inline styling.</p>
<img src="image.jpg" alt="My Image" width="200">
<a href="https://www.example.com" title="Go to Example.com">Visit Example</a>

Comments in HTML

HTML comments are used to insert explanatory notes in the code. They are ignored by the browser and are not displayed on the page. Comments are very useful for documenting your code and making it easier to understand. 


<!-- This is an HTML comment -->
<p>This paragraph is not a comment.</p>
<!--
    This is a
    multi-line
    HTML comment.
-->

<a href="https://www.w3schools.com" target="_blank">Visit W3Schools</a>

Test Your Knowledge

1. Explain the three main parts of an HTML element.
The three main parts are the start tag (marks the beginning), the content (the actual information), and the end tag (marks the end).
2. What is the importance of properly nesting HTML elements? Provide an example of incorrect nesting.
Proper nesting ensures that the browser can correctly interpret the structure of the HTML document. Incorrect nesting can lead to unexpected behavior and make the code harder to maintain. Example of incorrect nesting: <p><strong>Text.</p></strong>
3. What is the key difference between block-level and inline elements? Give one example of each.
Block-level elements start on a new line and take up the full width, while inline elements do not start on a new line and only take up necessary width. Example of block-level: <div>, Example of inline: <span>.
4. What are attributes in HTML? Provide an example of an HTML element with an attribute.
Attributes provide additional information about HTML elements. They are specified in the start tag as name/value pairs. Example: <img src="image.jpg" alt="My Image"> (src and alt are attributes).
5. How do you write a comment in HTML, and why are comments useful?
You write a comment in HTML using <!-- at the beginning and --> at the end. Comments are useful for adding explanatory notes to your code, making it easier to understand and maintain.
