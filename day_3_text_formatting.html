Structuring Content with Headings and Paragraphs

Well-structured content is easier to read and understand, both for users and search engines. HTML provides tags specifically for creating headings and paragraphs.

  • Headings (<h1> to <h6>): These tags define headings. <h1> represents the most important heading (usually the main title of the page or section), and <h6> represents the least important. Browsers typically display headings in larger and bolder fonts than normal text. It's crucial to use headings hierarchically (don't skip levels, e.g., go from an <h1> directly to an <h3> without an <h2>). There should generally be only one <h1> per page.
  • Paragraphs (<p>): This tag defines a paragraph of text. Browsers automatically add some vertical space (margin) before and after each paragraph. Any block of text that forms a distinct paragraph should be wrapped in <p> tags.

Basic Text Styling: Bold, Italic, Underline, etc.

HTML offers several tags to change the appearance or semantic meaning of text within a block (like a paragraph). These are often called "inline" elements.

Tag Description Typical Browser Rendering Semantic Meaning
<strong> Marks text with strong importance. Bold Indicates significant importance, seriousness, or urgency.
<b> Stylistically offsets text (historically "bold"). Bold Draws attention without implying extra importance (e.g., keywords, product names). Use <strong> if importance is intended.
<em> Marks text with emphasis. Italic Indicates stress emphasis, changing the meaning of the sentence.
<i> Stylistically offsets text (historically "italic"). Italic Represents text in an alternate voice or mood (e.g., technical terms, foreign words, thoughts). Use <em> if emphasis is intended.
<u> Represents text with an unarticulated, non-textual annotation (historically "underline"). Underline Often used for things like marking misspelled words or proper names in Chinese text. Avoid using it purely for decoration, as users often associate underlines with hyperlinks.
<mark> Represents text marked or highlighted for reference or notation purposes. Highlighted background (often yellow) Indicates text relevance in a specific context (e.g., highlighting search terms in results).
<sub> Defines subscript text. Lowered, smaller font Used for chemical formulas (H2O), mathematical variables, etc.
<sup> Defines superscript text. Raised, smaller font Used for exponents (x2), footnotes, ordinal numbers (1st), etc.
<small> Represents side comments or small print. Smaller font size Used for things like copyright notices or legal disclaimers.
<del> Represents deleted text. Strikethrough Indicates text that has been removed or is no longer accurate.
<ins> Represents inserted text. Underline (often) Indicates text that has been added to the document. Often used with <del>.

Important Note: While tags like <b> and <i> primarily define presentation (bold, italic), tags like <strong> and <em> carry semantic meaning (importance, emphasis). It's generally better to use the semantic tags when the meaning applies, as this benefits accessibility (screen readers can convey importance/emphasis) and search engines. Use <b> and <i> when there's no change in meaning, just style. For most styling, CSS is the preferred method, but these HTML tags are useful for specific semantic or stylistic inline adjustments.

Line Breaks and Horizontal Rules

  • Line Break (<br>): This is an empty tag (no closing tag needed) that forces a line break within a block of text (like inside a paragraph). Use it sparingly; if you need separate blocks of text, use multiple <p> tags. It's useful for things like addresses or poetry where line structure matters within a single block.
  • Horizontal Rule (<hr>): This empty tag represents a thematic break between paragraph-level elements. It's typically rendered as a horizontal line across the page. Use it to indicate a shift in topic or scene.

Examples

Example 1: Headings, Paragraphs, and Basic Styling


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Text Formatting Example 1</title>
</head>
<body>
    <h1>Main Page Title (h1)</h1>
    <p>This is the introductory paragraph. It provides context for the page.</p>

    <h2>A Major Section (h2)</h2>
    <p>This paragraph discusses the first main topic. We can use <strong>strong importance</strong> for key concepts and <em>emphasis</em> for stressed words. Sometimes, you might just want to draw attention using <b>bold</b> or <i>italics</i> for terms.</p>

    <h3>A Subsection (h3)</h3>
    <p>More details under the subsection. Let's highlight <mark>this important finding</mark>.</p>

    <h2>Another Major Section (h2)</h2>
    <p>Concluding thoughts.</p>
</body>
</html>

Example 2: Using Subscript, Superscript, Deleted, Inserted, and Small Text 


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Advanced Formatting</title>
</head>
<body>
    <h1>Scientific and Editorial Notations</h1>

    <p>The chemical formula for water is H<sub>2</sub>O.</p>
    <p>Einstein's famous equation is E=mc<sup>2</sup>.</p>
    <p>Please read the <small>terms and conditions</small> carefully.</p>
    <p>The original price was <del>$100</del>, now it's <ins>$75</ins>!</p>

    <!-- This shows how del and ins might be used together -->
    <p>The event is scheduled for <del>May 5th</del> <ins>May 12th</ins>.</p>
</body>
</html>

Example 3: Using Line Breaks and Horizontal Rules


<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Breaks and Rules</title>
</head>
<body>
    <h1>Structure Elements</h1>

    <p>Haiku Corner:<br>
    An old silent pond...<br>
    A frog jumps into the pond,<br>
    splash! Silence again.
    </p>

    <hr> <!-- Thematic break between different content sections -->

    <p>Mailing Address:<br>
    ACME Corp.<br>
    123 Main Street<br>
    Anytown, CA 90210
    </p>

    <hr>

    <p>This is the final section of the page.</p>
</body>
</html>

Test Your Knowledge

1. Which heading tag represents the most important heading on a page?

The <h1> tag.

2. What is the semantic difference between <strong> and <b>?

<strong> indicates strong importance or seriousness of the text, while <b> primarily represents a stylistic offset (like bold) without implying added importance.

3. When might you use the <br> tag appropriately?

It's appropriate for content where line breaks are part of the content itself, such as in poetry or mailing addresses, within a single block element like <p>.

4. What does the <hr> tag represent?

It represents a thematic break between paragraph-level elements, often visualized as a horizontal line. It signifies a shift in topic.

5. How would you write "CO2" (Carbon Dioxide) using HTML tags?

CO<sub>2</sub>
